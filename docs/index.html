Trombone

24 outils PDF.Rien ne part en ligne.

Une application Android, en français, qui fusionne, convertit, signe et protège vos PDF — et qui fait tout le travail sur votre téléphone.

Vos documents ne quittent jamais l'appareil. La plupart des applications PDF téléversent vos fichiers sur leurs serveurs pour les traiter. Pas celle-ci.

Un seul outil a besoin du réseau : « Page web vers PDF », pour aller chercher l'adresse que vous lui donnez. Les vingt-trois autres fonctionnent sans connexion.

Ce que fait l'application

  • Fusionner plusieurs PDF
  • Diviser, extraire, réordonner
  • Recto-verso à partir de deux scans
  • Images, Excel, PowerPoint vers PDF
  • Page web vers PDF
  • Scanner un document papier
  • PDF vers Word, Excel, PowerPoint
  • PDF vers images, PDF/A
  • Protéger par mot de passe
  • Déverrouiller un PDF
  • Caviarder, réparer
  • Signer, filigrane, numéros de page
  • Rogner, pivoter, comparer
  • Reconnaissance de texte (OCR)
